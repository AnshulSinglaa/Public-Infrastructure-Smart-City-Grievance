# Project review: whole repo, after Sprint 6 chat (tech lead, 2026-11-14)

Scope: everything in the repo, including the uncommitted Sprint 6 work. This is a report only, and no code was changed.
**Not repeated here:** the items already in `docs/FIX-PLAN-S6.md` (P1–P10, A–H) and `docs/BUGS.md`
B-056…B-076 (for example B-058 stream disconnect, B-059 Aadhaar, B-074 test_degraded_paths, B-075 status box).

**Tooling run (14 Nov):**
- `ruff check .`: clean.
- `pytest -q`: **369 passed, 1 failed (B-074, already filed), 1 skipped**, in 120 s.
- `pip-audit` on the uv.lock export: no known vulnerabilities.
- bandit `-ll`: 19 × B608 and 1 × B310, all reviewed and all false positives. The SQL builds only from constant table and column names, and the URL is a constant.
- semgrep p/python + p/github-actions: 1 false positive (`config.py:115` logs a file name, not a secret).
- Memory probe: importing `app.main` is about 170 MB, `litellm` adds about 120 MB, and the MiniLM reranker on 20 pairs adds about 350 MB. That gives a working set of about 640 MB, measured on Windows; Linux RSS is a little lower but still well over 512 MB.

Severity: **1 critical · 10 major · 24 minor · 5 nit** (40 findings).
